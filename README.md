## Current Research

**The 4-Beat Reflex for Grounded AI** — A reflex injection pattern that interrupts the fluent-answer impulse before the first token: **Stop. Search. Cite. Answer.** Each beat maps to an operational gate of the Law-4 Compliant™ Framework. Currently deployed in production on a fleet of specialized Hermes agents (LIMA), running local RAG pipelines with semantic search via Hermes/Llama.cpp.

**Active problems:**
- Response latency asymmetry: the fluent-answer impulse consistently outruns the verification procedure, even when a verified ground-truth source is available in context
- VRAM-bound reflex injection: benchmarking the 4-beat reflex across local quantizations to establish minimum-viable hardware profiles
- Continuous API evaluations: automated regression testing of the reflex against model provider API changes
